# AWS Certified Generative AI Developer - Professional (AIP-C01) Exam

I'm glad you're interested in learning more about this certification! Let me provide you with comprehensive details about the exam.

## Exam Overview

The **AWS Certified Generative AI Developer - Professional (AIP-C01)** is designed for developers who build and deploy production-ready generative AI solutions using AWS services. This is a professional-level certification that validates your ability to effectively integrate foundation models (FMs) into applications and business workflows.

## Target Candidate Profile

**Recommended Experience:**
- **2+ years** of experience building production-grade applications on AWS or with open-source technologies
- General AI/ML or data engineering experience
- **1+ year** of hands-on experience implementing GenAI solutions

**Required AWS Knowledge:**
- AWS compute, storage, and networking services
- AWS security best practices and identity management
- AWS deployment and Infrastructure as Code (IaC) tools
- AWS monitoring and observability services
- AWS cost optimization principles

## Exam Structure

**Format:**
- **75 total questions** (65 scored + 10 unscored for evaluation)
- **Question types:** Multiple choice, Multiple response, Ordering, Matching, and Case study scenarios
- **Passing score:** 750 out of 1,000 (scaled scoring)
- **Duration:** 180 minutes (3 hours)

## Content Domains & Weightings

The exam covers five major domains:

### 1. **Foundation Model Integration, Data Management, and Compliance (31%)**
- Analyzing requirements and designing GenAI solutions
- Selecting and configuring foundation models
- Implementing data validation and processing pipelines
- Designing vector store solutions
- Implementing retrieval mechanisms for FM augmentation
- Prompt engineering strategies and governance

### 2. **Implementation and Integration (26%)**
- Implementing agentic AI solutions and tool integrations
- Model deployment strategies
- Enterprise integration architectures
- FM API integrations
- Application integration patterns and development tools

### 3. **AI Safety, Security, and Governance (20%)**
- Input and output safety controls
- Data security and privacy controls
- AI governance and compliance mechanisms
- Responsible AI principles

### 4. **Operational Efficiency and Optimization (12%)**
- Cost optimization and resource efficiency strategies
- Application performance optimization
- Monitoring systems for GenAI applications

### 5. **Testing, Validation, and Troubleshooting (11%)**
- Evaluation systems for GenAI
- Troubleshooting GenAI applications

## Key AWS Services in Scope

**Core GenAI Services:**
- Amazon Bedrock (including Knowledge Bases, Prompt Management, Guardrails, Agents)
- Amazon SageMaker AI
- Amazon Q Business & Amazon Q Developer
- Amazon Titan models
- Amazon Comprehend
- Amazon Kendra

**Supporting Services:**
- AWS Step Functions (for orchestration)
- Amazon OpenSearch Service (for vector search)
- Amazon DynamoDB, Amazon RDS, Amazon Aurora
- AWS Lambda, Amazon API Gateway
- Amazon S3, Amazon ECS/EKS
- AWS CloudWatch, AWS X-Ray, AWS CloudTrail

## What's OUT of Scope

The exam does **NOT** cover:
- Model development and training from scratch
- Advanced ML techniques (deep learning architecture design)
- Data engineering and feature engineering
- Services like Amazon Redshift, AWS Batch, IoT services

## Key Concepts You'll Need to Master

- **RAG (Retrieval-Augmented Generation)** architectures
- **Vector databases and embeddings**
- **Prompt engineering** and management
- **Agentic AI systems** (multi-agent coordination, tool use)
- **Model Context Protocol (MCP)**
- **Responsible AI practices** (bias detection, content moderation)
- **Cost optimization** for GenAI workloads
- **Security and governance** for AI applications
